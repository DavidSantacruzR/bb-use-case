Build a small service that does two things. One: accept a file (an upload, or a local path) and store it in Backblaze B2. Two: after storing it, generate a short AI description of that file — a caption for an image or a summary for a text file — attach that description to the stored object as metadata, and return it to the caller along with the file name, size, and status. A minimal HTML page, a curl-able endpoint — your choice. If time allows, improve and iterate on the solution.
